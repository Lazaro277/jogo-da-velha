# ❌⭕ Jogo da Velha

Jogo da Velha desenvolvido com **HTML, CSS e JavaScript**, permitindo jogar contra outra pessoa ou contra o computador.

O projeto foi desenvolvido para praticar lógica de programação, manipulação do DOM, eventos e interatividade com JavaScript.

## 🎮 Funcionalidades

- Modo para 2 jogadores no mesmo dispositivo
- Modo contra o computador, com jogadas aleatórias
- Verificação automática de vitórias e empates
- Placar atualizado a cada vitória
- Exibição de mensagens com o resultado da partida
- Reinício automático do tabuleiro após cada rodada
- Bloqueio de jogadas durante a exibição do resultado
- Botão para retornar à seleção do modo de jogo

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/Lazaro277/jogo-da-velha.git
```

Depois, abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor.

## 📚 Aprendizados

Durante o desenvolvimento e aprimoramento deste projeto, foram praticados conceitos como:

- Manipulação de elementos HTML através do DOM
- Eventos de clique e interação com o usuário
- Estruturas condicionais e de repetição
- Funções e organização da lógica do jogo
- Uso de `setTimeout()` para controlar ações
- Geração de números aleatórios
- Controle de estados e validação das condições de vitória
